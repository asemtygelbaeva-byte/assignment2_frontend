## Основные вопросы

### Чем Flexbox отличается от Grid?

Flexbox обычно удобнее для одной основной оси: строки или колонки. Grid задаёт строки и столбцы одновременно. Здесь меню и карточки используют Flexbox, а галерея и структура журнала — Grid. Перенос строк через `flex-wrap` не превращает Flexbox в Grid: каждая flex-строка распределяет пространство отдельно.

### Что делают justify-content и align-items?

`justify-content` выравнивает элементы вдоль главной оси. `align-items` — вдоль поперечной. При `flex-direction: row` главная ось горизонтальная; при `column` — вертикальная.

В `.site-header` значение `space-between` разносит логотип и навигацию по сторонам, а `align-items: center` центрирует их по вертикали. Промежутки между ссылками создаёт `gap` у `.site-nav`.

### Почему карточки одной высоты?

`.card-row` использует `align-items: stretch`. Самая высокая карточка определяет высоту строки, остальные растягиваются до неё. У `.story-card` стоит `flex: 1 1 0`, поэтому ширина распределяется поровну. Высота всей карточки не задана фиксированным числом — текст может увеличиваться.

### Зачем flex-direction: column и margin-top: auto?

В `.card-content` элементы идут сверху вниз. Кнопка с `margin-top: auto` получает всё свободное место над собой и оказывается внизу. Поэтому кнопки выровнены даже при разной длине описаний.

### Что означает flex: 1 1 0?

Это сокращение для `flex-grow: 1`, `flex-shrink: 1`, `flex-basis: 0`. Карточки могут одинаково увеличиваться и уменьшаться, а распределение начинается с нулевой базовой ширины. `min-width: 0` разрешает flex-элементу сжиматься при длинном содержимом.

### Что такое fr и minmax(0, 1fr)?

`fr` — доля оставшегося свободного пространства Grid. `repeat(3, minmax(0, 1fr))` создаёт три равные колонки. Нижняя граница `0` разрешает колонке уменьшаться, не расширяя страницу из-за минимальной ширины содержимого.

### Как работают grid-template-areas и grid-area?

Родитель описывает карту:

```css
grid-template-areas:
  "header header"
  "sidebar main"
  "footer footer";
```

Дочерний элемент получает имя, например `grid-area: sidebar`. Повторение `header` в двух ячейках растягивает шапку на обе колонки. Именованная область должна быть прямоугольной. В мобильном media query карта переопределяется в одну колонку.

### Почему картинки не искажаются?

Контейнер задаёт размеры, а `object-fit: cover` сохраняет пропорции и обрезает лишние края изображения. В увеличенном просмотре используется `contain`, чтобы было видно фото целиком. Это разные задачи: одинаковые ячейки в галерее и полный кадр в просмотрщике.

### Как появляется подпись в галерее?

У `.gallery-item` стоит `position: relative`, а у `.gallery-caption` — `position: absolute`. Подпись прикреплена к нижнему краю своей карточки. При `:hover` и `:focus-visible` меняются `opacity` и `transform`. На сенсорных устройствах правило `@media (hover: none)` показывает подписи постоянно.

### Зачем box-sizing: border-box?

Так заданная ширина включает padding и border. Без него рамка и внутренние отступы добавлялись бы к ширине содержимого. Это упрощает расчёт размеров.

### Зачем нужны media queries?

Они меняют CSS при выполнении условия. До 760px карточки становятся колонкой, sidebar перемещается под проекты, а галерея получает две колонки. До 440px у галереи остаётся одна колонка. Дополнительная настройка до 1000px уменьшает отступы и меняет расположение элементов карточек портфолио.

### Для чего JavaScript?

Только для увеличенного просмотра фото. По нажатию скрипт читает `data-photo`, `data-title`, `data-caption`, обновляет содержимое `<dialog>` и вызывает `showModal()`. Закрытие снимает запрет прокрутки страницы. Вёрстка, Grid, Flexbox и hover-эффекты выполнены в CSS.

## Практика live coding

Перед упражнением сохрани копию `styles.css`. После каждого изменения обнови страницу и объясни результат. Затем верни исходный вариант.

### 1. Четыре колонки галереи

В основном правиле `.gallery-grid` замени:

```css
grid-template-columns: repeat(4, minmax(0, 1fr));
```

Проверяй на широком окне: мобильный media query может переопределить это свойство. Девятое изображение перейдёт в третью строку; Grid не обязан заполнять последний ряд полностью.

### 2. Увеличь промежутки между карточками

В `.card-row` измени `gap: 1.5rem` на `gap: 2rem`. Промежутки увеличатся, а карточки поделят оставшуюся ширину.

### 3. Поменяй sidebar и main местами

Для `.journal-page` одновременно измени карту и колонки:

```css
grid-template-columns: minmax(0, 1fr) 250px;
grid-template-areas:
  "header header"
  "main sidebar"
  "footer footer";
```

Одного изменения карты мало для хорошего результата: если сохранить исходные размеры колонок, статья попадёт в узкую колонку.

### 4. Сделай карточки вертикальными на компьютере

Добавь в `.card-row` `flex-direction: column`. Теперь главная ось вертикальная. Объясни, почему меняется смысл выравнивания по осям.

### 5. Убери выравнивание кнопок

Временно отключи `margin-top: auto` у `.card-content .text-link`. Кнопки окажутся сразу после описаний. Сравни карточки с разной длиной текста.

### 6. Измени границу мобильного вида

В media query замени `760px` на `900px`. Проверь на ширине 850px: сайт уже должен использовать более узкую компоновку.

## Частые ошибки при изменениях

- `display: flex` нужен родителю элементов, которые требуется расположить в ряд.
- Свойства `grid-template-*` работают у grid-контейнера, а `grid-area` — у его дочерних элементов.
- При изменении `flex-direction` меняются направления главной и поперечной осей.
- Более поздний media query может переопределить базовое правило.
- `height: 100%` требует подходящего контекста размеров; для обычных карточек растягивание и flex-колонки часто удобнее.
