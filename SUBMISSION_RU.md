## Сначала проверь локально

1. Распакуй архив целиком.
2. Открой `index.html` двойным щелчком.
3. Проверь Journal, Gallery, Portfolio и кнопки просмотра фото.
4. Прочитай `DEFENSE_RU.md` и самостоятельно выполни упражнения с CSS.

## Загрузка файлов или будущих обновлений на GitHub

1. Войди в свой аккаунт на [GitHub](https://github.com/).
2. Открой [репозиторий проекта](https://github.com/asemtygelbaeva-byte/assignment2_frontend).
3. В пустом репозитории выбери загрузку существующих файлов. В непустом — **Add file → Upload files**.
4. Перетащи **содержимое** распакованной папки: HTML, CSS, JS, Markdown-файлы, папки `assets` и `screenshots`. Загружай исходные файлы, а не один ZIP. `index.html` и `README.md` должны находиться в корне репозитория.
5. Сохрани загрузку с сообщением `Add Fieldnotes CSS assignment`.
6. Проверь, что на главной странице репозитория отображаются README и все скриншоты. Открой ссылку в приватном окне браузера: доступ не должен требовать входа.
7. Скопируй адрес репозитория и отправь его в Moodle до дедлайна.

Официальные инструкции: [создание репозитория](https://docs.github.com/en/get-started/start-your-journey/creating-a-repository-for-your-project-on-github), [загрузка файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).

## Дополнительно: сайт по ссылке

Для публичного просмотра самого сайта можно включить GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Дождись успешной публикации и используй адрес, который покажет GitHub. [Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

GitHub Pages — дополнение. Ссылку на репозиторий всё равно нужно сдать по условию задания.

## Перед защитой

- Имя и группа в README верны.
- В публичном репозитории есть все файлы и скриншоты.
- Локальная копия проекта открывается без интернета.
- Ты можешь найти CSS каждого из пяти заданий и изменить его без подсказки.
- Ты знаешь дату защиты и дедлайн в Moodle. В предоставленном задании конкретной даты нет.

По условиям преподавателя защита обязательна: без неё работа получает 0, даже если проект загружен вовремя.
